Student Management System - DepEd Grading
==========================================

QUICK START (Windows)
---------------------
1. Extract this ZIP to any folder
2. Double-click start.bat
3. Wait for npm install + build (1-2 minutes)
4. Browser opens automatically at http://localhost:8080
   (If 8080 is taken, auto-uses 8081, 8082, etc.)

DEFAULT LOGIN
-------------
Admin: admin@school.edu / admin123

NO XAMPP NEEDED!
----------------
This is a pure React app. No PHP, no MySQL, no XAMPP.
All data is stored in your browser (localStorage).

FEATURES
--------
- DepEd Order No. 8, s. 2015 Compliant Grading
- Track-based weights (Core, Academic, TVL)
- DepEd Transmutation Table
- Quarter-based grades (Q1-Q4)
- Semester Finals & GWA
- Attendance with consecutive absence drop rule
- Audit Logs
- Backup/Restore Database
- Printable Reports (Report Card, Class Record, Attendance)
- Built-in Documentation (Chapter 1-5, ER Diagram, Flowchart)
- Zero backend - runs entirely in browser

TECH STACK
----------
- React 18 + TypeScript
- Vite
- localStorage (JSON database)
- Node.js static server
